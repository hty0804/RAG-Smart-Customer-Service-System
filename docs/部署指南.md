# 部署指南（本地 → 云端）

本文档说明如何把本项目从「自己电脑上跑」变成「部署到服务器 / 云端，给别人访问」。

---

## 1. 本地运行回顾（生产等价命令）

本地演示用 `python main.py` 监听 `127.0.0.1`（仅本机）。
**部署到服务器务必监听 `0.0.0.0`**，否则外部访问不到：

```bash
python main.py --host 0.0.0.0 --port 8000
```

---

## 2. 用 Docker 部署（推荐，最省心）

项目已附带 `Dockerfile` 与 `.dockerignore`。

### 2.1 构建镜像

```bash
docker build -t rag-cs .
```

### 2.2 运行容器

**不要把 Key 写进镜像**，用环境变量传入：

```bash
docker run -d --name rag-cs \
  -p 8000:8000 \
  -e OPENAI_API_KEY=sk-你的真实key \
  -e OPENAI_BASE_URL=https://api.openai.com/v1 \
  rag-cs
```

启动后访问 `http://<服务器IP>:8000`。

> 如果用 Docker Compose，可把环境变量写在 `docker-compose.yml` 的 `environment` 中（勿提交含 Key 的 compose 文件）。

---

## 3. 部署到常见云平台（通用步骤）

本服务是一个标准 Python Web 服务（FastAPI + Uvicorn），以下平台任选其一，步骤大同小异：

1. **Railway / Render（海外，免费额度）**
   - 连接 Git 仓库，Build Command 填 `pip install -r requirements.txt`
   - Start Command 填 `python main.py --host 0.0.0.0 --port $PORT`（平台会注入 `PORT`）
   - 在平台后台的 Environment 里配置 `OPENAI_API_KEY` 等变量
2. **阿里云 / 腾讯云 / 华为云（国内）**
   - 在 ECS 上 `git clone` 本项目，`pip install -r requirements.txt`
   - 用 `nohup python main.py --host 0.0.0.0 --port 8000 &` 或 `systemd` 守护进程常驻
   - 在安全组 / 防火墙放行 8000 端口
3. **本地反向代理（生产建议）**
   - 前面加 Nginx/Caddy，把 80/443 转发到 8000，并配置 HTTPS

---

## 4. 上线前必看的安全与稳定性

- 🔑 **密钥安全**：Key 只通过环境变量 / 平台后台配置，**绝对不要写进代码、`.env`（已 gitignore）、或提交到 Git**。
- 🌐 **公网暴露风险**：直接把 8000 暴露在公网等于任何人都能调用你的 Key。务必：
  - 放在 Nginx 后并启用 HTTPS；
  - 加一层简单认证（如 Basic Auth / 访问口令），或仅限内网 / 加 IP 白名单；
  - 设置调用频率限制，防止 Key 被刷爆。
- 📈 **并发与性能**：Demo 用单进程 Uvicorn。正式场景可：
  - `uvicorn` 加 `--workers 2`（多进程）；
  - 知识库很大时把 `app/vector_store.py` 换成 FAISS（文件内有说明），检索更快。
- 💾 **数据持久化**：`data/index.npy` 与 `data/chunks.json` 是运行时生成物，已在 `.gitignore` 忽略；换机器后需重新跑 `python scripts/ingest.py` 构建索引。

---

## 5. 健康检查

部署后可先验证服务存活：

```bash
curl http://<服务器IP>:8000/health
# 期望返回：{"status":"ok","index_loaded":true,"mock":false}
```
