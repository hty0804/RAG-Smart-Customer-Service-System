# 使用上手文档（给非技术同事）

这份文档面向**不直接写代码**的同学：照着做就能把「智能客服」跑起来、并维护自己的知识库。遇到报错不要慌，第 5 节有常见问题对照表。

---

## 1. 这是什么

一个**会先查资料再回答**的客服机器人（技术上叫 RAG）。它不会凭空编答案，而是：

1. 你提问 → 2. 它去「知识库」里找最相关的几段内容 → 3. 把这些内容交给大模型 → 4. 大模型结合资料给你回复，并标出来源。

所以它**回答得准不准，主要取决于你的知识库写得好不好**。

---

## 2. 你需要准备什么

| 准备项 | 说明 | 怎么获取 |
| --- | --- | --- |
| 一台电脑 | Windows / macOS 均可 | 已有 |
| Python 3.10+ | 运行环境 | 见第 3 节一键安装 |
| 一个 API Key | 调用大模型的「通行证」 | 向负责人索取（OpenAI / DeepSeek 等均可） |

> 不需要懂编程，照着命令复制粘贴即可。命令里的 `$` 或 `>` 是提示符，**只复制它后面的内容**。

---

## 3. 三步跑起来

### 第 1 步：安装运行环境

打开「终端 / 命令行」（Windows 可用 PowerShell 或 Git Bash），粘贴：

```bash
pip install -r requirements.txt
```

如果提示 `pip` 找不到，先安装 Python（官网 python.org，勾选 "Add to PATH"），再重试。

### 第 2 步：填入你的密钥

在项目文件夹里，把 `_.env.example_` 复制一份并改名为 `_.env_`（注意前面有个点），用记事本打开，把里面的：

```ini
OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx
```

改成你拿到的真实 Key。例如：

```ini
OPENAI_API_KEY=sk-abC123......
```

> 如果你用的是 DeepSeek 等非 OpenAI 服务，除改 `OPENAI_BASE_URL` 和 `CHAT_MODEL` 外，还要按第 6 节配置向量化后端。

### 第 3 步：构建知识库并启动

```bash
python scripts/ingest.py     # 把知识库变成可检索的索引（只需做一次）
python main.py               # 启动服务
```

看到终端显示 `Uvicorn running on http://127.0.0.1:8000` 就成功了。
打开浏览器访问 **http://127.0.0.1:8000** ，就能开始对话了。

---

## 4. 怎么维护知识库（最重要）

所有「标准答案」都写在 `data/knowledge_base.txt` 这个文件里。

**编辑规则：**

- 用**空行**分隔不同主题，每个主题就是一条知识；
- 一个主题里可以写标题 + 若干说明；
- 改完保存后，**重新跑一次** `python scripts/ingest.py` 让改动生效。

示例：

```text
退款政策
用户可在收货后 7 天内申请退款，原路退回，1-5 个工作日到账。

发货时间
现货 24 小时内发货；定制商品 3-5 个工作日发货。
```

> 建议：知识库写具体、写明确，少写模糊话术。机器人只会从这里面找答案。

## 5. 常见问题（对照自查）

| 现象 | 可能原因 | 处理办法 |
| --- | --- | --- |
| 启动后浏览器打不开 | 端口被占用 / 没真正启动 | 确认终端显示 `Uvicorn running`；换端口：`python main.py --port 8080` |
| 回答里说「索引尚未构建」 | 没跑 ingest | 先执行 `python scripts/ingest.py` |
| 回答报错「401 / Invalid API key」 | Key 填错或过期 | 检查 `.env` 里的 `OPENAI_API_KEY` 是否正确、有无多余空格 |
| 回答明显瞎编 | 知识库没相关内容 | 在 `knowledge_base.txt` 补充对应内容并重跑 ingest |
| 中文乱码 | 文件编码非 UTF-8 | 用 VS Code / 记事本「另存为 UTF-8」 |
| 想先不填 Key 看界面 | —— | 用 `MOCK=1 python main.py` 启动（返回的是演示假数据） |

## 6. 切换为 DeepSeek（示例）

DeepSeek 当前用于对话生成；知识库向量化建议在本地完成。编辑 `.env`：

```ini
OPENAI_API_KEY=sk-你的deepseek key
OPENAI_BASE_URL=https://api.deepseek.com/v1
CHAT_MODEL=deepseek-chat
EMBEDDING_PROVIDER=local
EMBEDDING_MODEL=paraphrase-multilingual-MiniLM-L12-v2
```

先安装本地向量化依赖：

```bash
pip install -r requirements-local-embeddings.txt
```

然后重建索引并启动：

```bash
python scripts/ingest.py
python main.py
```

> 如果所在网络无法下载本地模型，可将 `EMBEDDING_PROVIDER=offline`，无需额外安装向量化依赖即可运行；但检索质量主要依赖词面匹配，适合演示或受限网络。
